# 砚页 YanYe 视觉规范

## 设计目标

砚页把办公软件的复杂能力压到内容之后。默认页面像一张米色纸面，正文使用温和的墨黑，导航、工具栏和状态反馈只承担必要的信息层级。

界面采用 Notion 风格的阅读基础，再补充文档编辑器、表格、白板和演示文稿需要的工具密度。每个工作区模块共享同一套颜色、间距、边框和动效规则。

## 颜色令牌

| 名称 | 值 | 用途 |
| --- | --- | --- |
| Ink | `#37352f` | 正文、标题、图标和主操作 |
| Paper | `#f7f6f3` | 应用底色和导航背景 |
| Page | `#ffffff` | 文档内容面和弹层 |
| Hover Grey | `#efedea` | 悬停、选中和轻量提示 |
| Hairline | `#e9e7e4` | 表格线、分隔线和输入框描边 |
| Link Blue | `#2eaadc` | 链接和引用 |
| Marker Red | `#eb5757` | 删除、错误和风险提示 |

## 排版

- 全局使用系统无衬线字体，优先使用 `ui-sans-serif`、Inter、Segoe UI 和 PingFang SC。
- 正文为 14px，行高 1.6。
- 正文大字为 16px，副标题为 20px，标题为 24px，页面标题为 32px。
- 正文字重使用 400，操作标签使用 500，标题使用 600。
- 正文内容宽度上限为 708px。外层左右各留 24px，桌面宽屏上随可用空间居中。

## 动效

- 所有 hover 只改变背景、文字或边框颜色。
- 过渡时间固定为 150ms。
- 页面块、按钮和输入框不使用位移、缩放或悬浮效果。
- 弹层可以使用 `0 8px 24px rgba(15, 15, 15, 0.12)` 的轻阴影。
- 拖拽手柄默认透明，悬停或聚焦时显示。
- 用户启用减少动态效果时，加载旋转动画停止。

## 组件规则

### 文档块

透明底、4px 圆角、4px 8px 内边距、14px 字号和 1.6 行高。悬停时只切换为 Hover Grey。

### Ghost Button

无描边、4px 圆角、13px 字号、16px 线性图标和 6px 图标间距。悬停时只改变背景。

### Inline Input

无背景和外框。聚焦时只显示 1px 底部线。占位符使用 60% 墨色。

### Callout

使用 Hover Grey 作为底色，4px 圆角，12px 16px 内边距，保留左侧图标位置。强调色按语义使用蓝、黄或红，同一页面控制强调色数量。

## 模块化扩展

文档、表格、白板和幻灯片共享以下视觉元素。

- 页面标题和面包屑
- 左侧工作区导航
- 顶部工具栏
- 可折叠的右侧属性或目录栏
- 底部保存状态和协作状态
- 同一套弹层、命令菜单和快捷键提示

电子表格和多维表格的网格使用可用宽度，超宽时只在网格内横向滚动。流程图保留自由画布，幻灯片保留页面比例。708px 的阅读栏只约束文档正文。

## 双入口与保存状态（下一阶段设计）

左侧一级导航提供「本地文件」和「工作区文稿」。前者列目录与文件名，后者列项目与文稿树。最近使用可以混排，但每一项显示所属位置，例如 `预算.xlsx · 项目资料` 与 `预算 · 秋季立项 / 工作区`。同名文件和文稿并排打开时，键盘读屏名称也要包含类型与位置。

| 用户动作 | 界面应给出的反馈 |
| --- | --- |
| 在磁盘目录中新建文件 | 先展示文件类型、文件名和目标目录。创建成功后，文件列表和编辑标签显示同一个文件名。 |
| 在项目下新建工作区文稿 | 先展示文稿类型和父项目。创建后直接进入编辑，通过面包屑可回到父项目。断网时沿用相同入口。 |
| 编辑已绑定文件 | 「草稿已保存 · 原文件待写入」与「已写入原文件」使用独立状态。外部改写导致保存冲突时，反馈留在当前标签内，提供保留草稿和另存副本的入口。 |
| 编辑工作区文稿 | 本机持久化成功后显示「已保存到本机」。断网时仍可输入、切换和导出。存储失败将提示保留在当前文稿和重试。 |
| 嵌入数据或图形 | 插入时区分「引用源内容」和「插入副本」。引用显示来源，可打开源对象；已有副本作为独立内容编辑。 |
| 打开大文件或取消转换 | 文件列表保持可操作，在对应标签显示读入阶段与取消按钮。结果准备好后替换占位视图，失败时提供原文件位置和可执行的恢复动作。 |

多人共享属于最后阶段。届时颜色旁同时显示人名，文字用插入点与选区、表格用单元格边框、流程图用画布坐标表示位置。滚动和缩放后仍锚定原内容，离开会话后移除标记。仅本机的文稿使用本地保存状态。

拖拽手柄用于规划中的块移动。手柄占 16px，聚焦时也可见，同一操作同时提供键盘入口。当前桌面版通过“页面操作 → 移动到”调整页面层级。

设计参考来自用户指定的 [StyleKit · Notion 风格](https://www.stylekit.top/zh/styles/notion-style)。
