## 用户目标与产品取舍

砚页是开源的 Windows 桌面办公软件，中文名取自砚台与书页，英文名 YanYe 与读音对应。办公室职员收到预算、合同或演示文件，可以在离线电脑上修改并交还原格式。项目负责人则可以维护一组持续变化的资料，包括会议记录、预算、行动项与审批图，并从中制作下一次评审的讲稿。

| 参照产品 | 采用的产品思路 | 砚页要解决的具体任务 |
| --- | --- | --- |
| WPS Office | 文字、表格、演示、PDF 具有独立的编辑工具和统一文件入口。[WPS Office](https://www.wps.com/office/) | 在同一窗口修改报价单、核对报价函、生成 PDF 定稿，并用接收方的软件重新打开交付文件 |
| Notion | 页面、内容块和数据库视图共同组织一个工作区。[Notion 内容块](https://www.notion.com/help/what-is-a-block) · [数据库视图](https://www.notion.com/help/views-filters-and-sorts) | 用同一条任务记录驱动清单、看板与日历，把决议关联到任务和流程节点 |
| ProcessOn | 流程图、泳道、专业图形库与可重用的图形模板。[ProcessOn 流程图](https://www.processon.com/flowcharts/) | 在断网现场画审批路径，插入判断与回退分支，调整泳道后仍可继续编辑 |

采购评审覆盖了整条跨工具工作流。用户离线打开供应商 XLSX，在砚页项目内整理预算，关联行动项与审批图，生成评审演示，并交付可编辑 PPTX 和阅读用 PDF。已有版本可以复制大纲并传递导出的图片。P1 进一步提供可追溯的引用、版本变化提示和按需刷新。

## 两种内容与所有权

产品入口采用「本地文件」与「工作区文稿」。后者对应产品愿景里的“在线文档”。**文稿类型与存放地点是两个维度。** 工作区文稿在本机就拥有完整内容、稳定的文稿 ID 和本地版本。未来它也可以直接创建在共享空间，或由所有者把本机文稿发布到共享空间。

| 规则 | 本地文件 | 工作区文稿 |
| --- | --- | --- |
| 用户创建的内容 | Word（DOCX）、Excel（XLSX）、PPT（PPTX）、PDF、Markdown（MD）、纯文本（TXT） | 电子文档、电子表格、演示稿、多维表格、流程图与白板 |
| 用户在哪里找它 | Windows 目录、文件中心、最近文件。用路径和扩展名交付 | 本机工作区的项目树、搜索、最近编辑。用文稿及对象 ID 维持引用 |
| 保存与关闭 | 自动暂存本机草稿，显式保存后更新磁盘文件，另存后切换到新文件。外部程序已修改时先解决冲突 | 编辑后持续写入本机工作区。显示「已保存到本机」后，关窗或重启可以恢复到已确认的版本 |
| 复制与交付 | 文件副本独立编辑，磁盘上的文件可直接传递给其他办公软件 | 导出标准文件生成当时的快照。未来通过共享同一份文稿共同编辑 |
| 移动与删除 | 文件中心改名或移动后应保留已打开的绑定。删除送入 Windows 回收站 | 项目内移动或改名保留 ID。删除进入工作区回收站，恢复后原链接重新可用 |
| 联网要求 | 六类本地任务可断网完成 | 本期创建位置为「此设备」，使用和重启均无需账号。未来新增「共享空间」 |

打开普通文件时，草稿只用来恢复对这份文件的编辑。用户主动选择「转换为工作区文稿」时，先显示源格式、可转换对象和可能简化的内容，再生成独立文稿并保留原件。原文件后续的编辑由用户决定是否再次导入。原路径只作本机来源信息。

「导出文件」选择格式、文件夹和名称，检查重名与丢失项。项目内引用的记录、图片或流程图固化为导出时的值或画面，源变更后可以重新导出。可移植备份应打包用户选择的依赖附件。重复导入为副本时建立新 ID，包内引用随之指向副本中的对象。缺失附件保留名称与占位，允许重新指定来源。删除源文稿时先展示引用它的页面，引用处能定位回收站或重新选源。

**本期新建流程。** 从「本地文件」新建时，用户选择类型、名称和磁盘目录。PDF 由现有文档或演示稿生成。从「工作区文稿」新建时，用户选择五类文稿之一、名称和项目位置，回车进入编辑。保存状态区显示实际写入结果。磁盘文件分别呈现「草稿已保存，文件有修改」「已写入文件」「原件发生变化」。工作区文稿呈现「保存中」「已保存到本机」或「保存失败，可重试」。写入失败的内容仍可从编辑器取回或另存。

### 一次采购评审如何验收跨模块引用（P1）

1. 断网打开供应商的 `报价.xlsx`，将明细转换为项目下的电子表格。两行费用为 4,800 元和 2,000 元，汇总为 6,800 元。记录原文件摘要。
2. 在评审电子文档中引用汇总区域，在多维表格建立「复核预算」行动项，指定负责人和日期。在流程图的「财务复核」节点关联这条记录。由电子文档生成演示初稿，把预算区域与审批图分别插入演示页，并导出第一份 PPTX。
3. 将项目电子表格中第二行改为 2,400 元。电子文档显示 7,200 元；演示页提示来源已更新，演示者选择刷新后才改变已排好的汇报稿。将行动项从「待处理」拖到「完成」，从节点和日历打开时均指向同一条已完成记录。
4. 重启并保持断网，引用仍能定位。分别用外部应用打开第一次导出的 PPTX 和刷新后另存的第二份，预算应分别为 6,800 元和 7,200 元。供应商原文件的摘要应与第一步一致。

## 0.3.0 已有编辑行为与格式边界

### 统一工作区与界面

文件中心提供 DOCX、XLSX、PPTX 和 Markdown 四个新建入口。选定本地目录后创建的文件直接出现在该目录，最近文件页的新建入口可通过 Windows 对话框选择保存位置。按文件名筛选、按名称或时间排序，进入子目录，新建文件夹，移动、重命名，或移到系统回收站。工作区页面的回收站只处理页面草稿，文件中心的回收操作针对磁盘项。

打开文件后，文件名显示在可切换的标签中。草稿自动保存到工作区。用「保存文件」或 `Ctrl+S` 更新磁盘文件，`Ctrl+Shift+S` 另存并切换到新文件。应用会检查读取时的文件摘要，外部改动与本机草稿冲突时可以另存。覆盖已有文件前保留一份上次的原件。

- 在文件中心或已打开的磁盘文件中，`Ctrl+N` 选择新的办公文件类型。在工作区草稿中，`Ctrl+N` 创建页面。要在项目下建表或画流程图，请打开项目的页面菜单，选择“新建子页面”。所有页面可收藏、移动和恢复。已绑定文件在文件中心重命名。
- `Ctrl+K` 搜索页面标题和可检索的文字内容。`Ctrl+S` 立即保存，其他编辑会自动保存。工作区保存在本机用户目录中。
- 写作区采用米纸色侧栏 `#f7f6f3`、墨色正文 `#37352f` 和 1px 浅色分隔线。正文阅读宽度上限为 708px，网格、图纸、幻灯片按各自编辑任务使用可用宽度。悬停以 150ms 颜色变化反馈，键盘用户可以通过焦点识别当前控件。[界面与动效规范](STYLE_SPEC.md)

### Markdown 文档

正文提供富文本和源码两种编辑入口。支持标题、行内格式、引用、代码块、图片、表格、任务清单和分隔线。`/` 菜单支持插入常用块及子页面。右侧文档大纲随标题更新，同时显示子页和任务完成情况。

Markdown 文件可以导入和导出。包含 frontmatter、脚注、指令块或原始 HTML 等语法时，编辑器优先使用源码，以保留原文。

### Word 文档

Word 页以纸张为编辑面。「开始」提供字体、字号、字色、粗体、斜体、下划线、段落样式、对齐、列表、查找和替换。「插入」可加入表格、PNG/JPEG 插图与手动分页符。「布局」可在 A4 与 Letter、纵向与横向之间切换并调整页边距。需要交付定稿时按纸张导出 PDF。

DOCX 读写覆盖基础段落和字符属性、标题、列表、表格及受支持的图片。外部文档中的页眉页脚、修订、复杂域、嵌入对象和多节版面可能简化。首次覆盖外部 Office 文件时提示另存副本或备份后写回。

### 电子表格

一本工作簿可有多张表。单元格保存输入值或公式，用户可以从网格或公式栏编辑。支持插入和删除行列、向下或向右填充、通过制表符和换行粘贴矩形数据。还可排序、筛选、冻结首行或首列，并为数值选择小数、百分比或人民币格式。

拖动、Shift 单击或 Shift 加方向键可扩展矩形选区。可复制粘贴多格、设字色底色和对齐、合并或拆分选区，支持撤销与重做。条件计算包含 IF、COUNTIF、SUMIF 和 COUNTA。XLSX 读写保留支持的选区样式和合并单元格。

- 公式支持 A1、绝对引用、跨表引用、区间、四则运算，以及 `SUM`、`AVERAGE`、`COUNT`、`MIN`、`MAX`、`ABS`、`ROUND`。例如，在合计格输入 `=SUM(B2:B6)`，再改动明细即可查看重算结果。
- 选中数字列可以显示柱状图。第一行作为表头，第一列作为标签，最多显示 20 个有效数值。
- CSV 适用于一张表的值，导出公式时写出计算结果。XLSX 支持多张工作表、原生公式和部分数字格式。应用内柱状图、宏、复杂样式和工作簿中的嵌入对象均超出当前 XLSX 交换范围。
- 每本上限 32 张表，每张最多 5,000 行、128 列，每格输入最多 32,767 个字符。

### 多维表格

多维表格按字段定义管理记录。首个文本字段表示记录名称。其余字段可选文本、数字、单选、日期、复选框、人员、关联记录或公式。人员字段保存本地填写的姓名，关联字段指向本表另一条记录，公式字段可对两个数值字段做加、减、乘、除。

| 视图 | 适合的操作 |
| --- | --- |
| 表格 | 设置字段、编辑值、筛选与排序，打开一条记录集中编辑 |
| 看板 | 按单选字段分组，拖动卡片即可改变这条记录的分组值 |
| 日历 | 选择日期字段，按月查看有排期的记录 |

三种视图使用同一组记录。每表上限为 64 个字段、5,000 条记录。JSON 备份可往返恢复字段、记录、关联和视图设置。CSV 与 XLSX 交换二维值，导入时按表头建立字段，XLSX 读取第一张工作表。需要保留原有字段配置时使用 JSON。

### 流程图与白板

画布支持流程步骤、起止节点、判断、泳道、便签、文本与手绘，可用模板起稿。连接两个节点后，拖动节点时连线端点会跟随，分支可填写标签。可以平移和缩放视图、适配全图、调整选中对象，以及撤销和重做。

- 继续在砚页编辑或备份整张白板时，使用 JSON。它保留图形、连接、笔迹和视口。
- 将白板用于文档或演示时，导出 SVG 或 PNG。Mermaid 文件 (`.mmd`) 适合交换流程节点与方向关系，笔迹和画布位置通过 JSON 保存。
- 本版的 Visio 类能力覆盖流程绘制和泳道。Visio 的 VSDX 文件交换属于后续兼容范围。

### 演示文稿

每份演示采用 16∶9 画幅。可以新增、复制、删除、调整页序，选择封面、标题与正文、两栏或图文版式，套用纸白、浅青或夜蓝主题。在图文页可插入本地 PNG、JPEG。每页可写演讲者备注。按 `F5` 从当前页放映，用方向键翻页，`Esc` 退出。

- 从工作区 Markdown 生成时，文档标题形成封面，后续标题形成幻灯片，标题下的文字成为对应页的正文。
- 可插入独立文本框，通过拖动或输入坐标确定位置，调整宽高、字号和颜色。文本框传递到放映、PDF 与 PPTX 中，PPTX 内可继续编辑。
- PPTX 导出包含可编辑的文本对象、图片和备注。导入会读取基础文字、讲者备注及支持的配图，按内置版式整理。任意形状布局、动画及音视频均超出此转换范围。
- PDF 按幻灯片逐页输出，保留主题颜色、版式与配图，放映画面和 PDF 仅呈现投影内容。需要交付备注使用 PPTX。

### 最后阶段的用户体验约定

当前开发预算全部用于 Windows 本地端。服务端部署、账号、共享空间与实时通信留待本地里程碑完成后单独立项。本期共享状态固定为「仅本机」。网络重新连接后，本地内容的共享范围保持原设置。

- **两条创建路径。** 将来「本机创建 → 发布共享」先选目标空间、确定会随文稿共享的依赖，再由所有者确认。共享成功后仍能找到原文稿和项目内引用。另一条路径是在有创建权限的共享空间直接新建。创建中断要保留草稿，重试后只出现一份目标文稿。
- **参与者与光标。** 有权限的用户打开共享文稿后，自己与其他人的姓名和颜色能区分。电子文档显示插入点或文字选区，电子表格显示单元格或范围，演示稿显示页和对象，多维表格显示记录和字段，流程图显示画布上的指针及选中的节点。离开、断线或撤权后其光标消失。光标移动不产生编辑历史，也不进入导出文件或备份。
- **断线与权限变化。** 断线后提示本机可继续的操作与待提交修改。重连时先核验权限。遇到无法自动合并的同一对象编辑，保留双方版本，允许选择或另存个人副本。只读参与者能查看最新版本，编辑操作按实际权限反馈。
