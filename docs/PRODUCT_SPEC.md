# 砚页 YanYe 产品设计说明

## 一个本地项目工作区

砚页把写作、计算、记录管理、画图和演示组织在一个 Windows x64 桌面窗口中。中文名取自砚台与书页，英文名 YanYe 与读音对应。0.3.0 的文件中心直接管理磁盘文件，页面树保留文档草稿、项目和白板。从 ONLYOFFICE Desktop Editors 借鉴了本地文件入口、多文件切换及文字、表格、演示三种专用编辑器的工作方式。[ONLYOFFICE 桌面编辑器](https://www.onlyoffice.com/desktop)

写作沿用 Typora 的连续文稿和源码切换思路，工作区借鉴 Notion 的页面树、子页与块命令。Excel 式网格适合依赖行列坐标的计算，飞书式多维表格适合围绕同一条记录切换视角。两类表都从“新建本地页面”进入，创建时即可选择适合手中数据的编辑方式。

一次本地项目评审可以这样准备。

1. 新建 Markdown 项目页，用二级标题列出预算、排期、审批三个议题。
2. 在项目页下建电子表格，用工作表分别记录明细与合计。再建多维表格，每条行动项记录负责人、状态和日期，切到看板推进状态，切到日历检查排期。
3. 在白板上画出审批路径，给分支加标签。导出 PNG 后，可以在演示文稿的图文页插入这张图片。
4. 在演示文稿中选择项目文档，按大纲生成幻灯片，补充备注并放映。生成时复制当时的文档内容，此后两边可独立修改。需要继续编辑的人可以拿到 PPTX，只需阅读的人可以拿到 PDF。

## 统一工作区与界面

文件中心提供 DOCX、XLSX、PPTX 和 Markdown 四个新建入口。选定本地目录后创建的文件直接出现在该目录，最近文件页的新建入口可通过 Windows 对话框选择保存位置。按文件名筛选、按名称或时间排序，进入子目录，新建文件夹，移动、重命名，或移到系统回收站。工作区页面的回收站只处理页面草稿，文件中心的回收操作针对磁盘项。

打开文件后，文件名显示在可切换的标签中。草稿自动保存到工作区。用「保存文件」或 `Ctrl+S` 更新磁盘文件，`Ctrl+Shift+S` 另存并切换到新文件。应用会检查读取时的文件摘要，外部改动与本机草稿冲突时可以另存。覆盖已有文件前保留一份上次的原件。

- 在文件中心或已打开的磁盘文件中，`Ctrl+N` 选择新的办公文件类型。在工作区草稿中，`Ctrl+N` 创建页面。要在项目下建表或画流程图，请打开项目的页面菜单，选择“新建子页面”。所有页面可收藏、移动和恢复；已绑定文件在文件中心重命名。
- `Ctrl+K` 搜索页面标题和可检索的文字内容。`Ctrl+S` 立即保存，其他编辑会自动保存。工作区保存在本机用户目录中。
- 写作区采用米纸色侧栏 `#f7f6f3`、墨色正文 `#37352f` 和 1px 浅色分隔线。正文阅读宽度上限为 708px，网格、图纸、幻灯片按各自编辑任务使用可用宽度。悬停以 150ms 颜色变化反馈，键盘用户可以通过焦点识别当前控件。[界面与动效规范](STYLE_SPEC.md)

## Markdown 文档

正文提供富文本和源码两种编辑入口。支持标题、行内格式、引用、代码块、图片、表格、任务清单和分隔线。`/` 菜单支持插入常用块及子页面。右侧文档大纲随标题更新，同时显示子页和任务完成情况。

Markdown 文件可以导入和导出。包含 frontmatter、脚注、指令块或原始 HTML 等语法时，编辑器优先使用源码，以保留原文。

## Word 文档

Word 页以纸张为编辑面。「开始」提供字体、字号、字色、粗体、斜体、下划线、段落样式、对齐、列表、查找和替换。「插入」可加入表格、PNG/JPEG 插图与手动分页符。「布局」可在 A4 与 Letter、纵向与横向之间切换并调整页边距。需要交付定稿时按纸张导出 PDF。

DOCX 读写覆盖基础段落和字符属性、标题、列表、表格及受支持的图片。外部文档中的页眉页脚、修订、复杂域、嵌入对象和多节版面可能简化。首次覆盖外部 Office 文件时提示另存副本或备份后写回。

## 电子表格

一本工作簿可有多张表。单元格保存输入值或公式，用户可以从网格或公式栏编辑。支持插入和删除行列、向下或向右填充、通过制表符和换行粘贴矩形数据。还可排序、筛选、冻结首行或首列，并为数值选择小数、百分比或人民币格式。

拖动、Shift 单击或 Shift 加方向键可扩展矩形选区。可复制粘贴多格、设字色底色和对齐、合并或拆分选区，支持撤销与重做。条件计算包含 IF、COUNTIF、SUMIF 和 COUNTA。XLSX 读写保留支持的选区样式和合并单元格。

- 公式支持 A1、绝对引用、跨表引用、区间、四则运算，以及 `SUM`、`AVERAGE`、`COUNT`、`MIN`、`MAX`、`ABS`、`ROUND`。例如，在合计格输入 `=SUM(B2:B6)`，再改动明细即可查看重算结果。
- 选中数字列可以显示柱状图。第一行作为表头，第一列作为标签，最多显示 20 个有效数值。
- CSV 适用于一张表的值，导出公式时写出计算结果。XLSX 支持多张工作表、原生公式和部分数字格式。应用内柱状图、宏、复杂样式和工作簿中的嵌入对象均超出当前 XLSX 交换范围。
- 每本上限 32 张表，每张最多 5,000 行、128 列，每格输入最多 32,767 个字符。

## 多维表格

多维表格按字段定义管理记录。首个文本字段表示记录名称。其余字段可选文本、数字、单选、日期、复选框、人员、关联记录或公式。人员字段保存本地填写的姓名，关联字段指向本表另一条记录，公式字段可对两个数值字段做加、减、乘、除。

| 视图 | 适合的操作 |
| --- | --- |
| 表格 | 设置字段、编辑值、筛选与排序，打开一条记录集中编辑 |
| 看板 | 按单选字段分组，拖动卡片即可改变这条记录的分组值 |
| 日历 | 选择日期字段，按月查看有排期的记录 |

三种视图使用同一组记录。每表上限为 64 个字段、5,000 条记录。JSON 备份可往返恢复字段、记录、关联和视图设置。CSV 与 XLSX 交换二维值，导入时按表头建立字段，XLSX 读取第一张工作表。需要保留原有字段配置时使用 JSON。

## 流程图与白板

画布支持流程步骤、起止节点、判断、泳道、便签、文本与手绘，可用模板起稿。连接两个节点后，拖动节点时连线端点会跟随，分支可填写标签。可以平移和缩放视图、适配全图、调整选中对象，以及撤销和重做。

- 继续在砚页编辑或备份整张白板时，使用 JSON。它保留图形、连接、笔迹和视口。
- 将白板用于文档或演示时，导出 SVG 或 PNG。Mermaid 文件 (`.mmd`) 适合交换流程节点与方向关系，笔迹和画布位置通过 JSON 保存。
- 本版的 Visio 类能力覆盖流程绘制和泳道。Visio 的 VSDX 文件交换属于后续兼容范围。

## 演示文稿

每份演示采用 16∶9 画幅。可以新增、复制、删除、调整页序，选择封面、标题与正文、两栏或图文版式，套用纸白、浅青或夜蓝主题。在图文页可插入本地 PNG、JPEG。每页可写演讲者备注。按 `F5` 从当前页放映，用方向键翻页，`Esc` 退出。

- 从工作区 Markdown 生成时，文档标题形成封面，后续标题形成幻灯片，标题下的文字成为对应页的正文。
- 可插入独立文本框，通过拖动或输入坐标确定位置，调整宽高、字号和颜色。文本框传递到放映、PDF 与 PPTX 中，PPTX 内可继续编辑。
- PPTX 导出包含可编辑的文本对象、图片和备注。导入会读取基础文字、讲者备注及支持的配图，按内置版式整理。任意形状布局、动画及音视频均超出此转换范围。
- PDF 按幻灯片逐页输出，保留主题颜色、版式与配图，放映画面和 PDF 仅呈现投影内容。需要交付备注使用 PPTX。

## 路线与交付顺序

后续本地设计保留以下方向，供逐项排期。

| 模块 | 后续设计 |
| --- | --- |
| 排版文档 | 自定义页面尺寸、页眉页脚、图注、交叉引用、样式集和更完整的 DOCX 往返 |
| 电子表格 | 条件格式、数据验证、自定义数值格式、更多图表与透视表 |
| 多维表格 | 附件字段、跨表关联、画廊、时间线与甘特视图，以及到期提醒 |
| 流程图与白板 | 对齐和吸附、分组和图层、UML 和组织结构图形、画布与文档互相引用 |
| 演示文稿 | 母版、演示者视图、计时器、嵌入图表与画布、标记原文变更并更新引用 |

下表按开发顺序排列。后续项目描述目标，版本和发布日期待定。

| 阶段 | 交付范围 | 如何验收 |
| --- | --- | --- |
| 0.1 本地写作 | Markdown 编辑、页面组织、搜索和自动保存 | 从源码切换到富文本，关闭并重启后仍可找到编辑的内容 |
| 0.2 本地办公 | 电子表格、多维表格、流程图与白板、演示文稿及上述文件交换 | 修改明细后核对合计，拖动看板卡片后核对记录，移动节点后核对连线，从文档生成并导出演示 |
| 0.3 文件中心与 Office 文件 | 磁盘文件管理、文档标签、DOCX 文字处理、XLSX 选区与样式、PPTX 编辑与原文件保存 | 选目录新建、移动及重命名文件，直接打开外部文件编辑写回，重开核对，外部变更时保留原件 |
| 后续本地编辑与文件兼容 | 分节、页眉页脚、审阅与复杂排版，扩展公式、图表、绘图图形和演示版式 | 用代表文件检查版式、计算结果、往返保留的对象及兼容提示 |
| 后续本地数据管理 | 工作区备份恢复、附件管理与本地历史 | 从备份恢复项目，确认页面、引用与附件完整，能够取回旧稿 |
| 最后开发团队文档协作 | 在所有本地里程碑之后引入账号、共享权限、批注、多人同步编辑、断线重连和冲突处理 | 两台机器共同修改一份获授权文档，断线重连后内容收敛，访问权限生效 |
