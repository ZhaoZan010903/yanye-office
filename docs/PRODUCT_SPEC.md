# 砚页 YanYe 产品设计说明

## 产品定位

砚页 YanYe 是一款面向 Windows 的开源协作办公工作台。它把 Markdown 写作、文档排版、数据表格、关系型多维表、流程图与白板、演示文稿和团队协作放进同一个页面工作区。

当前 0.1 版可在 Windows 本机完成 Markdown 编辑、页面管理和保存。以下用一个项目评审过程说明目标产品如何把各模块连接起来。

1. 负责人从 Markdown 草稿开始，在项目页写下评审议题，邀请同事共同修改。
2. 编辑者在多维表中给每条行动项分配负责人和日期。同一条记录可以出现在表格、看板和日历里，在任一视图更新状态都会反映在其他视图。
3. 财务成员在工作簿里算出预算合计，把引用该区域的图表插入项目页。流程负责人在白板上连接审核节点，将流程图链接到同一页。
4. 主讲人从文档大纲生成幻灯片，选中要带入的图表。工作稿引用源对象，评审定稿时可冻结快照。只读观众能看到哪些引用，由源对象的共享权限决定。

## 名称与品牌

- 中文名称为“砚页”，取自砚台与书页，强调沉静写作和长期积累。
- 英文名称为“YanYe”，保持短、易读、便于仓库和命令行使用。
- 开源仓库名称为 `yanye-office`。

## 目标用户

### 个人创作者

- 用 Markdown 记录知识、研究、日志和项目计划
- 把长文直接整理成演示文稿或任务清单
- 依靠本地文件工作，并在需要时开启同步

### 小型团队

- 共同编辑需求文档、会议记录和项目资料
- 用多维表格维护任务、客户、资产和内容日历
- 用白板完成流程梳理、头脑风暴和架构讨论

### 产品与研发团队

- 使用文档、表格、流程图和演示稿组成完整交付物
- 通过评论、提及、版本和权限完成评审
- 需要 Windows 桌面端的离线能力和企业内网部署选择

## 信息架构

```text
工作区
├── 首页与最近访问
├── 页面树
│   ├── 文档页
│   ├── 表格页
│   ├── 白板页
│   ├── 演示页
│   └── 数据库页
├── 我的任务
├── 收藏
├── 搜索
├── 模板中心
├── 回收站
└── 工作区设置
```

工作区是权限和同步的基本单元。页面既可以独立存在，也可以嵌套在文档、数据库或项目页面内。页面树只负责组织，页面内容由对应模块负责渲染。

## 功能地图

### 1. Markdown 与文档编辑器

当前 0.1 版已经支持以下写作操作。

- Markdown 源码和富文本双向切换
- 标题、段落、列表、任务、引用、代码、表格、图片和分隔线
- `/` 块命令
- 目录、字符数、任务完成进度
- Markdown 导入与导出
- 原始 HTML、脚注和 frontmatter 的源码优先模式

后续版本计划加入以下能力。

- 文档模板和快速插入
- 文档评论、批注和版本历史
- 导出 PDF、DOCX 和 HTML

当前按页持久化 Markdown。计划给可协作文档的每个块分配稳定 ID，使评论能跟随段落移动，允许离线修改在重连时按块合并。

### 2. Word 级排版文档

文档模块基于同一套块模型提供打印级排版。

- 页面尺寸、页边距、页眉页脚和分页符
- 多级目录、编号列表和交叉引用
- 样式集，包括正文、标题、引用、代码和说明
- 表格合并、单元格样式和自动调整
- 图片、附件、图注和脚注
- 修订模式、批注和接受或拒绝修改
- DOCX 导入和导出
- PDF 预览与打印

Markdown 页面进入排版模式后，保留原始内容并增加版式属性。版式属性独立于 Markdown 文本，避免导出时破坏源文件。

### 3. Excel 与多维表格

表格模块分成两层。

#### 电子表格

- 多工作表和冻结窗格
- 公式、引用、自动填充和格式刷
- 单元格格式，包括数字、日期、货币、百分比和自定义格式
- 筛选、排序、分组、条件格式和数据验证
- 图表、透视表和 CSV、XLSX 导入导出
- 大数据量下的虚拟滚动

#### 多维表格

- 一张数据表对应一个实体集合
- 字段类型包括文本、数字、日期、人员、选择、复选、附件、公式和关联
- 视图包括表格、看板、日历、画廊、时间线和甘特图
- 过滤器、排序、分组、字段权限和视图权限
- 自动化触发器，例如新增记录、状态变化和到期提醒
- 记录详情页可以直接打开为文档子页

多维表格使用结构化记录存储，电子表格使用网格和公式存储。两者可以通过导入、关联和嵌入互通。

### 4. Visio 类画图与白板

画布模块服务于流程图、架构图和自由画布。

- 无限画布和缩放
- 形状库，包括流程图、UML、网络、组织结构和泳道
- 自动吸附、对齐、分布、连接线和端点
- 图层、分组、锁定和组件复用
- 思维导图、流程图、时序图和简单原型
- 多人光标、区域评论和演示模式
- SVG、PNG、PDF 和 Mermaid 导出

画布对象使用 JSON 图形模型保存。文档块可以嵌入画布缩略图，画布中的节点也可以链接回页面或表格记录。

### 5. PPT 与幻灯片

演示模块优先服务于“从内容生成演示”。

- 幻灯片页面、母版、版式和主题
- 文本、图片、形状、表格、图表、视频和画布嵌入
- 对齐、分布、参考线和图层面板
- 演讲者备注、计时器和演示者视图
- 从文档标题和大纲生成初稿
- 从表格和图表生成数据页
- PPTX、PDF 和图片导出

演示页与文档页共享内容引用。修改原文后，演示页可以标记受影响的内容，用户决定是否更新。

### 6. 实时协作与 Docs 能力

- 实时多人编辑
- 在线状态和光标
- 评论、回复、解决和提及
- 页面级、数据库级和工作区级权限
- 只读、评论、编辑、管理四种角色
- 分享链接和到期时间
- 版本历史和恢复
- 离线编辑与重新连接后的增量同步
- 冲突提示和可解释的合并结果

协作功能以页面和记录为边界，附件和导出任务独立排队。用户可以在无网络状态下继续编辑已有内容。

### 7. 搜索与工作流

- 标题、正文、表格记录、评论和附件名称搜索
- 过滤模块、作者、更新时间和标签
- 快速打开、最近访问和收藏
- 页面内反向链接和关系图
- 任务汇总、截止日期和提醒
- 命令面板统一执行新建、插入、导出、分享和切换模块

## Windows 体验与规划

- Electron 外壳，统一使用自定义协议和上下文隔离
- Windows 11 风格的标题栏与快捷键
- 文件拖放、系统剪贴板和文件对话框
- 离线优先，本地工作区可以完全不连接云端
- 可打包为便携版、安装包和企业内网版本
- 未来可通过原生模块支持系统通知、托盘和自动启动

## 视觉设计

本产品采用 StyleKit 的 Notion 风格规范。

- 画布使用 `#f7f6f3` 米色纸面
- 正文和图标使用 `#37352f` 暖墨色
- hover 使用 `#efedea`
- 分隔线使用 `#e9e7e4`
- 链接使用 `#2eaadc`
- 删除和错误使用 `#eb5757`
- 使用系统无衬线字体，优先 `Segoe UI`、`PingFang SC` 和 `Inter`
- 正文宽度控制在 708px 左右
- 常规圆角使用 4px
- hover 只改变颜色和背景，150ms 完成
- 拖拽手柄在 hover 时出现
- 弹层可以有轻量阴影，正文画布不使用重阴影

## 快捷键设计

0.1 已提供 Ctrl+K、Ctrl+N、Ctrl+S 和斜线命令。下表的模块切换、命令面板与评论快捷键属于后续设计。

| 快捷键 | 动作 |
|---|---|
| `Ctrl+K` | 搜索工作区 |
| `Ctrl+N` | 新建页面 |
| `Ctrl+S` | 立即保存 |
| `Ctrl+Shift+P` | 打开命令面板 |
| `Ctrl+Alt+1` | 文档模式 |
| `Ctrl+Alt+2` | 表格模式 |
| `Ctrl+Alt+3` | 白板模式 |
| `Ctrl+Alt+4` | 演示模式 |
| `/` | 插入内容块 |
| `Ctrl+Enter` | 提交评论或确认记录 |

## 分阶段路线图

### V0.1 写作工作区

- 当前已完成的页面树、Markdown 编辑、任务、表格、搜索、回收站和本地保存
- Windows x64 便携版
- 基础安全配置和自动化测试

### V0.2 文档合写试点

- 稳定块 ID
- 页面模板
- 图片和附件管理
- 评论与版本历史
- 页面分享、查看和编辑权限，可选自托管同步服务
- 验收：两台 Windows 设备编辑同一段落，其中一台离线后继续输入，重连后两份文档收敛且均保留输入。被撤销权限的设备重连时，可将待同步的改动保留为本地副本。

### V0.3 电子表格与多维表格

- 记录模型和字段系统
- 表格、看板和日历视图
- 公式和关联字段
- CSV 和 XLSX 导入导出
- 电子表格先交付工作表、单元格引用、求和、筛选和 CSV 交换。验收时修改被引用单元格，核对总计随之重算，并检查不同多维视图展示同一记录的最新值。

### V0.4 白板与流程图

- 无限画布
- 基础形状库和连接线
- Mermaid 和 SVG 导出
- 文档和画布互相嵌入
- 验收：拖动审批节点后连线仍连接同一节点，重新打开图形后可继续编辑。

### V0.5 幻灯片与排版文档

- 页面版式和主题
- 文档打印布局
- PPTX 和 DOCX 导出
- 内容引用和演示模式
- 验收：用同一份三节文档生成演示初稿，嵌入图表、补充备注后放映，并用样本核对 PPTX 和 DOCX 的支持项。

### V0.6 跨模块团队协作

- 将文档试点使用的同步服务扩展到表格、画布和幻灯片
- 多人光标和评论
- 权限、分享链接和审计
- 离线队列和冲突合并
